Flow channel lists

This site serves signed, versioned copies of community channel lists for the Flow apps. Flow for Android and Flow Desktop check it about once a day, and only while the user has the matching filter turned on.

There is no server behind it: a daily job builds static JSON files under /v1/. The catalogue is at /v1/index.json.

Data source and licence

The aislist list mirrors AiSList (Override92/AiSList), a community list of YouTube channels that mainly publish AI-generated content. The data is licensed under CC BY-NC 4.0 and must not be used commercially.

Code and file formats: Flow-Tube/AIlist.
